# Aria 带宽控制功能

## 概述

Aria的带宽控制功能提供了一套完善的QoS（服务质量）管理系统，通过eBPF技术实现实时流量控制。系统支持四级优先级的带宽限制机制，能够对网络流量进行精细控制。

## 四级限速架构

### 1. 服务级（最高优先级）
- **匹配条件**：五元组（源IP、目标IP、源端口、目标端口、协议）
- **优先级**：最高
- **应用场景**：微服务间精确控制、高安全要求场景、特定应用限速

### 2. 端口级（中等优先级）
- **匹配条件**：端口号（可结合特定IP）
- **优先级**：中等
- **应用场景**：服务级别流量控制、端口安全防护、应用类别管理

### 3. Peer级（较低优先级）
- **匹配条件**：两个IP地址间的通信（双向）
- **优先级**：较低
- **应用场景**：服务器间通信控制、容灾备份限速、负载均衡集群

### 4. IP级（最低优先级）
- **匹配条件**：单个IP地址
- **优先级**：最低
- **应用场景**：客户端控制、租户隔离、防资源滥用

## 匹配逻辑

系统按照优先级顺序检查规则：
1. 当数据包到达时，BPF程序按优先级顺序检查
2. 如果找到更高优先级的匹配规则，则应用该规则并跳过后续检查
3. 只有在较高优先级的规则都不匹配时，才会应用较低优先级的规则
4. 如果没有规则匹配，则允许数据包通过（默认行为）

## 功能特性

- **实时控制**：通过eBPF技术实现实时流量控制
- **优先级管理**：四级优先级架构确保关键业务优先
- **灵活配置**：支持多种匹配条件和带宽限制
- **可视化界面**：直观的Web界面管理所有规则
- **批量操作**：支持批量应用和清除规则

## 使用说明

### 1. 添加规则
- 点击"添加"按钮打开规则编辑对话框
- 选择规则类型（服务级/端口级/Peer级/IP级）
- 根据类型填写相应的匹配条件
- 设置带宽限制值
- 保存规则

### 2. 管理规则
- 编辑现有规则
- 删除不需要的规则
- 查看规则详情

### 3. 应用规则
- 点击"应用规则"将所有配置应用到系统
- 规则立即生效，影响实时流量

### 4. 清空规则
- 点击"清空规则"移除所有配置
- 慎用此功能，会导致所有带宽限制失效

## API接口

### 规则管理
- GET /api/qos/rules - 获取所有规则
- POST /api/qos/service - 创建服务级规则
- PUT /api/qos/service/{id} - 更新服务级规则
- DELETE /api/qos/service/{id} - 删除服务级规则

- POST /api/qos/port - 创建端口级规则
- PUT /api/qos/port/{id} - 更新端口级规则
- DELETE /api/qos/port/{id} - 删除端口级规则

- POST /api/qos/peer - 创建Peer级规则
- PUT /api/qos/peer/{id} - 更新Peer级规则
- DELETE /api/qos/peer/{id} - 删除Peer级规则

- POST /api/qos/ip - 创建IP级规则
- PUT /api/qos/ip/{id} - 更新IP级规则
- DELETE /api/qos/ip/{id} - 删除IP级规则

### 系统控制
- POST /api/qos/apply - 应用所有规则
- DELETE /api/qos/clear-all - 清空所有规则
- GET /api/qos/stats - 获取统计信息

## 技术实现

带宽控制功能基于eBPF技术实现，具体包括：

- XDP/TC层数据包处理
- 三级限速架构：服务级 > Peer级 > IP级
- 支持TCP/UDP头部解析
- 五元组精确匹配
- 实时流量统计

## 安全考虑

- 所有API调用需要认证
- 规则修改具有审计日志
- 支持租户隔离
- 权限控制系统

## 性能指标

- 数据包处理延迟 < 1微秒
- 支持百万级并发连接
- 内存占用低
- CPU开销最小化
