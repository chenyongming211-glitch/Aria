# v0.1.0 E2E Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the v0.1.0 demonstrable end-to-end paths for onboarding, control, and operations, then prepare one deployable build for online full testing.

**Architecture:** Keep this phase narrow: reuse current token, node, policy delivery, monitoring, AI chat, and agent command APIs. Add missing frontend workflow glue, context preservation, validation tests, and deployment evidence; do not redesign Agent/eBPF, IM cards, or autonomous remediation.

**Tech Stack:** Vue 3, Element Plus, Vitest, Go Controller APIs, existing `agent_commands`, `policy_deliveries`, `alerts`, `audit_events`, local Controller/frontend build flow plus GitHub Actions for full gate.
